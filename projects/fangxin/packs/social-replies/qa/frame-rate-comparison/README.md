# 帧率对照

本目录只用于选择《方芯回你了》的最终补间采样率，不是发布资产。APNG 使用浅色 QA 背景，动作总时长沿用包内动作卡；各档差异只来自中间姿态数量。

| 档位 | 采样率 | 中间姿态 | 用途 |
| --- | ---: | --- | --- |
| A current | 20 fps | 不补间，保持当前关键帧式观感 | 基线 |
| B balanced | 30 fps | 从确定性动作参数重绘 | 平滑度与成本的平衡候选 |
| C double | 40 fps | 从确定性动作参数重绘 | 约为当前采样率 2 倍的上限候选 |

代表动作：

- S02 不行：快速大幅旋转，最容易看出跳帧，也最容易暴露错误补间。
- S05 谢谢：核心亮度与柔光微动，验证高帧率对细微变化是否有实际收益。
- S11 真的假的：慢速单侧倾斜，验证较长动作是否更连贯。

所有 B/C 预览都直接插值旋转、形变、核心亮度和文字透明度，再由包内脚本逐帧重绘；不使用重复帧或光流补帧。逐文件采样数、编码帧数与文件大小见 [`manifest.json`](manifest.json)。

最终选择已锁定为 B / `30 fps`：它明显消除 A 的关键帧跳变，而 C / 40 fps 在三类代表动作上的额外收益不足以抵消新增逐帧 QA 与编码成本。全包生产结果见 [`../30fps-review.json`](../30fps-review.json)。
