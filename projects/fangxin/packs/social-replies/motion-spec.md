# 《方芯回你了》动态动作卡 v1.1

本文档锁定《方芯回你了》S01-S12 的逐帧动作、文字位置、时长、循环和制作边界。角色身份与视觉规则以 [`../../identity/spec.md`](../../identity/spec.md) 为准，语义清单与使用场景以 [`README.md`](README.md) 为准。

## 1. 全包规则

- 每张固定使用 5 个关键帧，总时长控制在 `1.2～1.6 秒`；第 4 帧是语义停留帧，常规停留 `580～640 ms`，S04 为避免笑声动作过快延长到 `740 ms`。
- 第 1 帧与第 5 帧保持接近，循环端点平均 RGBA 差必须小于 `8`。
- 右上缺角、中央核心外框、主体色相、眼距和 2.5D 材质跨帧稳定；核心实体贴色必须使用锚点真实内芯像素遮罩，不得用外框内缩估算矩形替代。S01 与 S11 允许在内芯上缘增加 `6 px` 同色覆盖层消除白线。S02 先以通道色差 `<45` 的近白像素定位真实内芯包围框，再生成连续圆角遮罩；珊瑚红柔光强度限制为常规值的 `25%`，不得染色外框。核心只允许约 `5%～8%` 的弹性形变，扩亮时只能放大柔光场，不能让实体色块越出内芯。
- S01 不使用文字；S02、S04 在核心下方机身留白区分别使用文字 `NO`、`hhh!`；其他表情的精确文案统一后期确定性合成。
- 文字居中放在核心下方的正面区域：2 个字使用 `72 px`，3～4 个字使用 `64 px`；Sarasa Mono SC SemiBold、深青色、轻微内嵌、不发光。
- 每张只有一个主语义动作。眼形、核心亮度和文字只用于加强该动作，不增加手脚、嘴、场景、第二主体或额外剧情。
- 5 个关键帧继续作为动作、停留和循环真值；更高帧率必须从确定性动作参数重绘中间姿态，禁止用重复帧冒充流畅度，也禁止把有重影的光流补帧作为生产源。
- 最终采样率锁定为 `30 fps`。每张按动作总时长生成 `37～47` 个中间帧，单帧时长为 `33～34 ms`；参数化补间常规最大过渡窗口为 `120 ms`，S04 为放慢波浪使用 `190 ms`，第 4 关键帧的语义停留段保持静止。S09 的半闭眼与常态眼属于离散身份资产，采用干净切换，禁止交叉混合造成双眼重影。

## 2. 锚点与确定性合成

| 锚点 | 用途 | 权限 |
| --- | --- | --- |
| `work/anchors/rgba/neutral-rgba.png` | 常态、缩放、摇摆、核心节奏 | 已验证工作锚点，不替代身份母版 |
| `work/anchors/rgba/half-eyes-rgba.png` | 无语、拒绝、晚安及惊讶前态 | 首包已验证眼形的本包副本 |
| `work/anchors/rgba/happy-eyes-rgba.png` | 笑死 | 首包已验证开心眼形的本包副本 |
| `work/anchors/rgba/focus-eyes-rgba.png` | 真的假的 | 首包已验证专注眼形的本包副本 |
| `work/anchors/rgba/s07-jiayou-generated-v1-rgba.png` | 加油 | 只批准用于 S07，不向其他表情扩散 |

除 S07 的既有专用锚点外，其余动作优先通过确定性位移、缩放、旋转、局部形变、亮度、眼形切换和文字图层完成。只有确定性方案在视觉 QA 中失败时，才允许补充新的姿态锚点。

## 3. S01 OK

- 主动作：绿色小勾从核心右下缘短促画出。
- 通道：常态眼、绿色核心、核心右下缘小勾；无文字。
- 禁止：占用右上缺角；把小勾放在垂直中轴形成嘴；复用首包“收到”的开心回弹。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 180 ms | 常态眼、青白核心，缺角保持纯粹。 |
| 2 | 160 ms | 主体轻压，核心转绿，小勾开始从核心右下缘画出。 |
| 3 | 160 ms | 主体短促回弹，小勾完整，核心达到绿色高亮。 |
| 4 | 580 ms | 小勾贴合核心右下缘稳定停留，表达同意或许可。 |
| 5 | 180 ms | 小勾淡出，核心回到青白并衔接首帧。 |

## 4. S02 不行

- 主动作：主体围绕底部中心完成一次左右拒绝摇摆。
- 通道：半闭横眼、珊瑚红核心、核心下方机身文字 `NO`。
- 禁止：珊瑚红轮廓偏离真实内芯或染色外框；连续抖动成故障；加入叉号或第二种信号；把 `NO` 放进核心或移到核心上方；与首包“别催”的下沉回弹混同。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 180 ms | 半闭横眼、低亮珊瑚红核心，核心下方机身文字 `NO` 低透明度出现。 |
| 2 | 150 ms | 以底部中心为支点向画面左侧转约 `7°`，机身文字 `NO` 同步显现。 |
| 3 | 150 ms | 越过中线向画面右侧转约 `7°`，核心和机身文字 `NO` 同步提亮。 |
| 4 | 580 ms | 回到中线，半闭横眼、红色核心和核心下方 `NO` 稳定停留，形成拒绝收束。 |
| 5 | 180 ms | 回到与首帧接近的低亮拒绝态，机身文字 `NO` 回落后循环。 |

## 5. S03 无语

- 主动作：左上先主塌，左下稍后轻跟随。
- 通道：半闭横眼、低亮灰青核心、文字“无语”。
- 禁止：整块刚性倾斜；只拉低底角；变成困倦、过热或装死。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 180 ms | 左上刚开始失去支撑，文字低透明度出现。 |
| 2 | 180 ms | 左上明显下塌，左下开始轻微跟随，核心降亮。 |
| 3 | 180 ms | 非对称软塌接近峰值，文字基本可读。 |
| 4 | 600 ms | 左上降幅约为左下两倍，右侧与缺角稳定，文字完全可读。 |
| 5 | 180 ms | 左上先回弹、左下只留轻微软塌，文字淡出并循环。 |

## 6. S04 笑死

- 主动作：本体产生一次放慢的左右交替柔软波浪；实体 `^ ^` 眼只随同一波浪局部微晃，不形成独立眼部动作。
- 通道：本体形变、实体 `^ ^` 眼、青白核心、机身文字 `hhh!`。
- 禁止：绿色完成核心；垂直庆祝弹跳；纸屑或第二层笑声符号；双眼与主体反向或不同步地独立摇晃。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 200 ms | `^ ^` 眼、低亮青白核心，主体保持基线，`hhh!` 低透明度出现。 |
| 2 | 220 ms | 上下轮廓形成第一相位的柔软横向波浪，双眼随主体局部上移。 |
| 3 | 220 ms | 波浪反相，双眼同步向相反方向轻移，核心与 `hhh!` 提亮。 |
| 4 | 740 ms | 主体恢复为略微舒展的开心姿态，`^ ^` 眼、青白核心和 `hhh!` 稳定停留。 |
| 5 | 200 ms | 回到接近首帧的轻微余震，眼部与文字同步回落后循环。 |

## 7. S05 谢谢

- 主动作：状态核心完成一次柔和扩亮。
- 通道：常态眼、青白核心、文字“谢谢”。
- 禁止：鞠躬、爱心、双手合十或绿色完成态；实体内芯不得扩张，只有柔光场可在外框允许范围内扩散。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 180 ms | 核心低亮，文字低透明度出现。 |
| 2 | 180 ms | 核心光场扩张约 `3%`，亮度上升。 |
| 3 | 180 ms | 核心光场扩张到约 `6%` 并达到峰值，文字基本可读。 |
| 4 | 620 ms | 核心回落到约 `4%` 的温和高亮，文字“谢谢”稳定停留。 |
| 5 | 180 ms | 核心和文字回落到接近首帧后循环。 |

## 8. S06 没事

- 主动作：轻微内缩状态平滑恢复稳定。
- 通道：常态眼、青白核心、文字“没事”。
- 禁止：摇头、挥手、开心弹跳；不能与发送者主动“抱歉”方向混淆。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 180 ms | 主体轻微内缩约 `3.5%`，核心低亮，文字开始出现。 |
| 2 | 180 ms | 主体恢复到约 `98.5%`，核心逐渐稳定。 |
| 3 | 180 ms | 主体轻微越过基线约 `1%`，形成柔和释然回弹。 |
| 4 | 600 ms | 主体回到常态，青白核心和“没事”稳定停留。 |
| 5 | 180 ms | 回到接近首帧的轻微内缩态后循环。 |

## 9. S07 加油

- 主动作：蓄力压缩后向前上方推进。
- 通道：专注眼、青白核心、文字“加油”。
- 禁止：绿色完成态、开心眼、尾迹或跑步；不能读成自己“跑通了”。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 180 ms | 前倾锚点轻压，核心和文字低亮。 |
| 2 | 140 ms | 主体继续蓄力压缩，核心与文字提亮。 |
| 3 | 160 ms | 主体向前上方推进并抬升，核心达到高亮。 |
| 4 | 600 ms | 前倾推进姿态、青白核心和“加油”稳定停留。 |
| 5 | 180 ms | 回到轻压状态，核心和文字回落后循环。 |

## 10. S08 辛苦了

- 主动作：主体缓慢前倾致意。
- 通道：常态眼、青白核心、文字“辛苦了”。
- 禁止：缩成疲惫或受压状态；加入汗、礼物或第二主体；不能替代面向未来的“加油”。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 200 ms | 主体保持直立，文字低透明度出现。 |
| 2 | 200 ms | 上部轮廓开始缓慢前压，核心略降。 |
| 3 | 200 ms | 前倾致意接近峰值，文字基本可读。 |
| 4 | 620 ms | 上部下移约 `3%`、底部稳定，形成克制致意并停留。 |
| 5 | 200 ms | 主体开始恢复直立，文字淡出并循环。 |

## 11. S09 厉害

- 主动作：主体短促后仰，双眼从半闭前态睁回常态最大包围框。
- 通道：半闭眼到常态方眼、青白核心、文字“厉害”。
- 禁止：眼睛超过身份最大包围框；绿色完成核心；奖杯、星星或与首包“跑通了”相同的庆祝弹跳。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 160 ms | 半闭前态、核心低亮，文字开始出现。 |
| 2 | 140 ms | 双眼睁回常态方眼，主体开始后仰。 |
| 3 | 160 ms | 上部向后打开并上提约 `2%`，核心快速提亮。 |
| 4 | 600 ms | 常态最大眼形、短促后仰姿态和“厉害”稳定停留。 |
| 5 | 160 ms | 回到接近首帧的半闭前态后循环。 |

## 12. S10 抱歉

- 主动作：主体内收并轻微下沉。
- 通道：常态眼、低亮灰青核心、文字“抱歉”。
- 禁止：哭泣、眼泪、跪下或鞠躬；不能演成接受对方道歉的“没事”。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 200 ms | 主体接近常态，核心偏低亮，文字开始出现。 |
| 2 | 200 ms | 主体向内收缩约 `2%` 并下沉。 |
| 3 | 200 ms | 内收达到约 `4%`，下沉约 `18 px`，文字基本可读。 |
| 4 | 620 ms | 克制的内收下沉姿态、低亮核心和“抱歉”稳定停留。 |
| 5 | 200 ms | 主体开始恢复，文字淡出并循环。 |

## 13. S11 真的假的

- 主动作：主体缓慢向一侧倾斜审视。
- 通道：专注眼、黄色低亮核心、文字“真的假的”。
- 禁止：左右摇摆；问号、弹窗或第二层疑问符号；不能退化成负向“无语”。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 180 ms | 专注眼、低亮黄色核心，文字开始出现。 |
| 2 | 200 ms | 主体围绕底部中心向画面右侧慢倾约 `2.5°`。 |
| 3 | 200 ms | 慢倾加深到约 `5.5°`，核心提亮。 |
| 4 | 620 ms | 向单侧倾斜约 `7°` 的审视姿态和“真的假的”稳定停留。 |
| 5 | 180 ms | 回到接近首帧的小角度倾斜后循环。 |

## 14. S12 晚安

- 主动作：保持直立，缓慢下沉、闭眼并降亮。
- 通道：低亮横眼、参照 S10 降亮方向但更明显加深的暗灰青核心、文字“晚安”。
- 禁止：趴平、装死、月亮、床或完整夜景；不能变成广播自己“困了”。

| 帧 | 时长 | 画面 |
| --- | ---: | --- |
| 1 | 220 ms | 半闭横眼、低亮核心，文字开始出现。 |
| 2 | 240 ms | 主体保持直立并缓慢下沉约 `8 px`，整体略微降亮。 |
| 3 | 240 ms | 下沉到约 `18 px`，核心以增强暗化强度继续熄暗，文字基本可读。 |
| 4 | 640 ms | 下沉约 `26 px`、横眼和明显加深的暗灰青核心稳定，文字“晚安”停留。 |
| 5 | 220 ms | 主体回到接近首帧的浅下沉状态后循环。 |

## 15. 集中审核清单

1. S01 的小勾是否贴核心右下缘且不形成嘴，缺角是否保持纯粹。
2. S02 是否是一次明确拒绝摇摆，`NO` 是否位于核心下方机身留白区，而不是核心内部、故障抖动或“别催”。
3. S03 是否上重下轻地软塌，而不是整体倾斜。
4. S04 是否由放慢的横向柔软波浪表达大笑；双眼是否只随主体局部微晃，`hhh!` 是否在停留帧清楚，并与绿色完成庆祝分离。
5. S05 与 S06 是否分别读成感谢和安抚，而不只是换文案。
6. S07 与 S08 是否分别面向未来鼓励和认可既有投入。
7. S09 是否赞赏对方，且没有复制首包“跑通了”的成功语法。
8. S10 与 S06 的发送方向是否相反且动作可区分。
9. S11 是否是单侧审视，不是 S02 的左右拒绝。
10. S12 核心是否比原版明显加深，同时仍然直立收尾，不进入首包“装死”的趴平区间。
11. 除保留既有处理的 S03 外，所有着色核心的实体色块是否逐像素贴合真实内芯，只有柔光允许越过内芯边缘。
12. 最终 30 fps 补间是否来自参数化重绘且无重影；S09 眼形是否干净切换，快速、微动和慢动三类动作是否都保持语义停留。
