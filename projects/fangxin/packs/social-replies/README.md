# 《方芯回你了》

内部 ID：`social-replies`  
表情包状态：`completed`；微信 v1 发布候选为 `ready_for_submission`  
表情数量：12 张  
目标平台：微信表情开放平台；12 张 GIF 与品牌素材已完成，等待后台提交

这是一套面向朋友、熟同事、伴侣和非正式小群聊的即时回应包。方芯以克制、干巴、略带温度的语气，回应对方刚刚提出的安排、情绪、帮助、努力或聊天收尾。每张脱离 AI 或工作语境也能成立；AI 气质只通过右上缺角、状态核心、本体形变和像素语言表达。

## 1. 使用边界

- 每张必须能接在对方一条具体消息后面，或明确结束一段聊天。
- 不汇报检索、生成、推理、工具调用或故障状态。
- 允许短文字精确锁定语义；动作负责情绪和语气，文字全部后期确定性合成。
- 不增加手脚、嘴、复杂场景、第二主体或多层剧情。
- 眼形与核心是基础通道；文字或外部特效最多再选一类。

## 2. 冻结语义清单与建议顺序

| 编号 | 表情 | 核心回复意图 | 主语义动作 | 文字 | 优先级 |
| --- | --- | --- | --- | --- | --- |

| S02 | 不行 | 拒绝请求或不可接受的安排 | 主体围绕底部中心左右摇摆一次 | 核心下方机身文字 `NO` | P1 |
| S03 | 无语 | 对荒谬或难以评价的内容表示无奈 | 左上先主塌、左下稍后轻跟随 | 需要 | P0 试片 |
| S04 | 笑死 | 对好笑内容作强烈正向反应 | 放慢的左右交替波浪，开心眼随主体微晃 | 机身文字 `hhh!` | P1 |
| S05 | 谢谢 | 感谢对方的帮助、信息或照顾 | 核心完成一次柔和扩亮 | 需要 | P1 |

## 3. 真实发送节点

| 表情 | 典型上文 | 不能替代的相邻语义 |
| --- | --- | --- |
| OK | “下午三点开会行吗？”“那我按 A 方案做？” | 首包“收到”只确认接收，不批准提议 |
| 不行 | “今晚再通宵改一版？”“能顺手再加三个需求吗？” | 首包“别催”要求停止催促，不拒绝请求 |
| 无语 | “需求没变，只是全部重做。”“他又把线上库删了。” | 不是困倦、过热或装死 |
| 笑死 | 对方发来明显好笑的截图或荒诞经历 | 不是自己任务完成后的庆祝 |
| 谢谢 | “我帮你把文件改好了。”“给你留了一份饭。” | 不是确认收到或许可方案 |
| 没事 | “抱歉，刚才忘回你了。”“我是不是添麻烦了？” | 与发送者主动说“抱歉”方向相反 |
| 加油 | “明天面试，我有点紧张。”“还有最后一公里。” | 面向未来，不是认可已经付出的辛苦 |
| 辛苦了 | “终于把第六版报告改完了。”“昨晚一夜没睡。” | 认可既有投入，不是感谢自己获得帮助 |
| 厉害 | “我拿到 offer 了。”“第一次半马跑进两小时。” | 赞赏对方，不是汇报自己“跑通了” |
| 抱歉 | “你怎么又忘记回复我了？”“这里的数字写错了。” | 主动修复，不是接受对方道歉 |
| 真的假的 | “明天突然全员放假。”“他一次就修好了线上问题。” | 要求核验，不是负向“无语” |
| 晚安 | “我先睡了。”“今天先聊到这里吧。” | 关系收尾，不是广播自己困了 |

## 4. 表达与制作决策

- S01 不使用文字；S02、S04 分别在核心下方的机身留白区使用确定性内嵌文字 `NO`、`hhh!`。去掉文字后，S02 仍应由摇摆、半闭眼和红核心读成拒绝，S04 仍应由开心眼和柔软波浪读成大笑。
- 其余表情去掉文字后至少应读出正确情绪功能；精确回复意图由机身短文字锁定。
- S03、S04、S07、S08、S09 需要明显姿态变化；除 S07 的既有专用锚点外，当前均先使用身份稳定工作锚点做确定性形变，只有视觉 QA 失败时才补新锚点。
- 生图阶段禁止模型生成文字；文字使用与首包一致的方正等宽中粗、深青色内嵌语言。
- 全包关键动作与时长已锁定在 [`motion-spec.md`](motion-spec.md)；S01、S02、S04-S12 的核心着色使用真实内芯像素遮罩，S03 保留既有核心处理。S12 进一步加深暗灰青核心，避免降亮过程不明显。

## 5. 代表性试片门槛

| 试片 | 验证目标 | 必须通过的对照 |
| --- | --- | --- |
| S01 OK | 高频语义与核心签名 | 与首包“收到”并排时不能互换；小勾贴核心右下缘但不能读成嘴，缺角保持纯粹且在 240×240 及聊天图标尺寸可辨 |
| S03 无语 | 方芯签名软体形变 | 不能读成困倦、CPU 过热、已读装死或整块倾斜；左上降幅约为左下两倍，软塌后缺角、眼距和核心保持稳定 |
| S07 加油 | 无手脚条件下的推进与鼓励 | 不能读成自己“跑通了”或任务“在推了”；前倾锚点仍像同一个方芯 |

三张均已通过透明边缘、浅深背景、小尺寸、循环接缝、身份稳定和语义停留帧检查。逐帧真值记录在各试片源包的 `motion.json`；只有全包逐帧动作锁定后才创建本包 `motion-spec.md`。

## 7. 不纳入本包

- 困了、摸鱼、自我封印：偏自我状态广播或退出，且与晚安、装死相邻。
- 检索中、生成中、重试中、在推了、脑子满了、工具炸了、开始乱编了：属于 AI 或工作状态，不符合本包使用边界。
- 等下、别客气、早安、拜拜、恭喜、好家伙、抱抱：分别因首包或本包内部重叠、使用边界不符、发送频率不足或身份动作代价过高而不纳入。
