# 像素小人 v2 身份动态试片

- 状态：`superseded_by_v3`
- 身份输入：[`../../masters/master-v1-32.png`](../../masters/master-v1-32.png)
- 工作框：`48×48`
- 试片数量：3
- 首发平台：微信优先，但本目录资产保持平台中立

v2 根据 v1 用户评审生成：放弃含义不清的“卡住了”；“收到”增加由角色发出的 `Got it!` 像素气泡；“我看一下”视觉不变并改名为“工作中”；第三张改为人物身体表达更明确的“崩了”。用户随后认为 v2 的“崩了”身体变化不明显、看不出正在趴下，因此本版已被 [`../v3/README.md`](../v3/README.md) 取代。

## 试片

| 内部 ID | 语义 | 主动作 | v1 关系 |
| --- | --- | --- | --- |
| `received` | 收到 | 点头，右侧两行气泡显示 `GOT / IT!`，尾巴指向空白脸区 | 重做 |
| `working` | 工作中 | 前倾，双手在屏幕/键盘边交替轻动 | 逐帧复用 v1 `take-a-look` |
| `crashed` | 崩了 | 头部落到键盘，肩膀塌下，双臂摊开；抬起后再次趴下 | 替换 v1 `stuck` |

`GOT / IT!` 是 `Got it!` 在 `48×48` 工作框中的两行大写像素排版。气泡提供说话来源，但脸区仍没有嘴或任何五官。

三张统一使用 5 帧、4 个独特姿态、总时长 `1.2s`，时长依次为 `480 / 120 / 120 / 120 / 360ms`；首帧和末帧使用同一主语义姿态，保证长停和闭环。

## 通过门槛

1. `收到` 的气泡明确属于角色发言，且文字在 `50×50` 下仍可辨。
2. `工作中` 能直接读成持续敲键盘，不再使用“我看一下”语义。
3. `崩了` 依靠身体与键盘关系表达崩溃，不依赖故障图标或文字。
4. 三张仍属于同一无脸角色，首帧可读、循环自然、Alpha 二值、深浅背景稳定。

三张全部通过后，才进入首包 8 张规划。
