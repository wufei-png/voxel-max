# 像素小人 v3 身份动态试片

- 状态：`superseded_by_v4`
- 身份输入：[`../../masters/master-v1-32.png`](../../masters/master-v1-32.png)
- 工作框：`48×48`
- 试片数量：3

v3 只重做“崩了”：v2 虽然移动了头部，但身体主轴和头发方向变化不足，第一眼不容易看出正在趴下。v3 明确展示“批准母版坐直 → 双手抬起 → 头肩下沉并侧转 → 侧趴在键盘上”的全过程。用户随后要求改为正面朝下、落地只显示全黑头顶，因此本版已被 [`../v4/README.md`](../v4/README.md) 取代。

`收到`与`工作中`逐帧复用 v2，不作视觉修改。

## 试片

| 内部 ID | 语义 | 主动作 | v2 关系 |
| --- | --- | --- | --- |
| `received` | 收到 | 点头并显示由角色发出的 `GOT / IT!` 气泡 | 逐帧复用 |
| `working` | 工作中 | 前倾并持续敲键盘 | 逐帧复用 |
| `crashed` | 崩了 | 从坐直姿态起，双手抬起、头肩下沉，头部身份块旋转 90° 后侧趴到键盘 | 重做 |

三张统一为 5 帧、4 个独特姿态、总时长 `1.2s`，时长为 `480 / 120 / 120 / 120 / 360ms`。`崩了`的首末帧都是已趴下的主语义姿态；循环中先短暂坐起，再完整倒下，兼顾静态首帧与动作过程。

## 通过门槛

1. `崩了`在不看名称时仍能看出人物从坐直到倒在键盘上的过程。
2. 旋转后的头部仍保留黑发、空白脸区和台阶关系，不能像独立道具。
3. `收到`与`工作中`必须与 v2 原帧一致。
4. 三张首帧可读、循环自然、Alpha 二值、深浅背景和 `50×50` 稳定。

三张全部通过后，才进入首包 8 张规划。
