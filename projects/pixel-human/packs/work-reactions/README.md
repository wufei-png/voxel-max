# 小同事上班记

- 内部 ID：`work-reactions`
- 公开角色名：像素小同事
- 公开专辑名：小同事上班记
- 状态：`ready_for_submission`
- 规格：9 张透明动态表情
- 首发优先：微信
- 平台中立源工作框：`48×48`

本包以已经通过的身份试片动作为首个生产切片。用户在首轮包评审后重新分配两个倒地动作：v3 的侧趴键盘用于“崩了”，v4 的正面全黑头顶用于新增“磕头”。完整动作以 [`motion-spec.md`](motion-spec.md) 为准。

最终版本已经锁定：`S01 收到` 使用 [`v05-chat-card`](explorations/got-it/candidates/v05-chat-card/)，`S04 开会中` 使用 [`work/v5`](work/v5/)，`S09 磕头` 使用 [`work/v6`](work/v6/) 的块状手掌优化版，其余六张沿用当前通过版本。旧候选只保留为设计追溯，不再参与首发选择。

## 选择依据

1. 三张通过试片完整保留，避免重新验证已经成立的语义。
2. 新增动作补足等待、临时占用、成功反馈、角色化负面反应、离场和强烈社交表达，没有再加入与“工作中”高度重叠的“我来处理 / 在写了”。
3. 九张形成一条实际工作聊天链路：`收到 → 稍等 → 工作中 → 开会中 → 搞定了 / 崩了 → 无语 → 磕头 → 下班了`。
4. `S01` 使用确认气泡，`S08` 使用离场后逐字标题；其余优先靠姿态、道具和通用符号表达。
